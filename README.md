# おくちたいそう（口腔トレーニング記録PWA）

V kids（マウスピース矯正）と並行して歯科医院から指示された口腔筋機能トレーニングを、
毎日「朝・昼・夜」に続けるための子ども向けアプリ。記録はそのまま歯科医への月次レポートになる。

## フォルダ構成
```
okuchi-taiso/
├── index.html            アプリ本体（単一HTML・外部依存なし）
├── manifest.json         PWA設定
├── sw.js                 Service Worker（オフライン対応）
├── icons/
│   ├── icon-180.png      iPhoneホーム画面用
│   ├── icon-192.png
│   ├── icon-512.png
│   └── icon-maskable-512.png
└── README.md
```

## 公開・インストール（GitHub Pages）
1. GitHubで新規リポジトリ（例：`okuchi-taiso`）を作り、このフォルダの中身をそのままアップロード
2. Settings → Pages → Branch: `main` / `(root)` で公開
3. iPhoneのSafariで `https://<ユーザー名>.github.io/okuchi-taiso/` を開く → 共有 → 「ホーム画面に追加」
4. 「かがみ」機能（フロントカメラ）は https 必須。初回にカメラ許可を求められます（映像は保存・送信しません）

## 収録トレーニング（初期値＝配布シートの目安の下限）
| 種目 | 形式 | 初期目標 | シートの目安 |
|---|---|---|---|
| マンチーもぐもぐ | タイマー | 5分 | 5〜10分 |
| すいあげ | タイマー | 1分×2回 | 1分×2回 |
| すいあげキープ | ストップウォッチ記録 | 120秒 | 2分以上 |
| バルーンチーク | タイマー | 1分 | 1〜3分保持 |
| リップポップ | 回数 | 30回 | 30〜60回 |
| おなかで しんこきゅう（腹式呼吸） | タイマー＋呼吸ガイド | 1分 | 1〜3分 |
| ティックトック／リズム | 回数（自動リズム可） | 10回 | 10〜20回 |
| イーウー | 回数 | 30回 | 30〜60回 |

各種目の説明文は子ども向けに言い換えたもの。保護者用チェック項目は各画面の「おうちのひと チェック」に格納。
目標値・種目のON/OFF・朝昼夜の実施有無は「おうちのひと」画面で変更可能（歯科医の指示に合わせて調整）。

## 主な機能
- **きょう**：朝・昼・夜のカード。今の時間帯を自動でハイライト。進捗バー
- **ガイド付き実施**：1種目ずつ、イラスト・読み上げ・かがみ（カメラ）・タイマー/カウンター。終わると自動で次へ
- **ごほうび**：1セッション完了で⭐1、⭐3つでシール1枚（全40種）。連続日数表示
- **カレンダー**：日ごとの朝昼夜の達成ドット。全部できた日は動物シール
- **記録の修正**：カレンダーの日付 →「なおす」（保護者ロック付き）で付け忘れを後から記録
- **マウスピース記録**：項目名は自由設定（初期値「ねるとき」「ひる（おうち）」— 実際の装着指示に合わせて変更）
- **歯科医用レポート**：月別の実施表（朝/昼/夜・マウスピース・キープ最高記録・実施率）。印刷/PDF、テキストコピー
- **保護者ロック**：「おうちのひと」タブは足し算で解除（10分有効）
- **バックアップ**：JSONで書き出し／読み込み

## データについて
- 記録は端末内（localStorage）のみ。サーバー送信なし
- iPhoneでは「ホーム画面のアプリ」と「Safari」で保存領域が別。必ずホーム画面から使う
- 機種変更・アプリ削除の前に「バックアップを書き出す」

## 更新するとき
`index.html` を差し替えたら `sw.js` の `VERSION` を上げてpush（キャッシュ更新のため）。

## 注意
トレーニング内容・回数は担当歯科医の指示が優先。アプリの初期値は配布シートの目安を写したもので、医療的判断は含まない。
